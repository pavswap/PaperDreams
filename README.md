A simple side-scroller game made with Python, Pygame and Paper.

## How to Run

1. Install Python: https://www.python.org/
2. Install Pygame:
```bash
pip install pygame
```
   or
Play the [PaperDreams WebPort](https://pavswap.github.io/PaperDreams/) on the browser
